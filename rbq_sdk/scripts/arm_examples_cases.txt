# Cases for arm_examples_check.py - one line each: example | arguments | exit code | checks...
#   example    the number of the example (01 .. 08)
#   arguments  as typed after the program name (may be empty)
#   exit code  what the example must return
#   checks     each one a piece of its output: plain text must be there, !text must not
# Every case runs on the C++ and the Python example, and the two must print the same (bar the program name).
# A valid command ends at its "[dry-run] <target> <call>" line - the call it would make, without connecting.
