# 내장 사운드 출처

전부 [위키미디어 공용](https://commons.wikimedia.org)의 퍼블릭 도메인·CC0 파일이다. 소리가 시작되기 직전부터
(앞 무음 ≤0.15 s) 10초 이내로 자르고(끝 0.3 s 페이드), `loudnorm I=-20` 2패스(linear)로 음량을 맞춰
64 kbps mono mp3 로 바꿨다. loudnorm 이 linear 를 거부하거나(피크 초과) 짧은 파일이라 빗나가면
같은 목표(-20 LUFS)로 게인 + 리미터(-1.5 dBFS)를 걸었다 — 결과는 전부 -20 ±0.7 LUFS(2026-10-06 재작업).

## 교체 이력 (2026-10-06)

- `dog` — 이전 원본 `Dog in Antefasy.wav` 는 아주 작게(피크 0.07) 녹음된 2.3 s 파일로, 분류 모델이 사람 말소리(Speech 0.82)로 판정하고 개 짖음은 잡지 못했다.
- `doorbell-dingdong` — 이전 원본 `Doorbell-classic-dingdong.ogg` 는 0.5 s 타격 뒤 9.5 s 가 울림 꼬리라 초인종으로 들리지 않았다(Doorbell 판정 없음).
- `eagle` — 이전 원본 `Bald Eagle Yellowstone National Park.ogg` 는 클리핑·잡음이 심했다(신호/배경 차 3 dB).
- `hawk` — 이전 원본 `Roadside Hawk Belize.mp3` 는 고양이 울음처럼 들리는 종이다(Owl/Cat 판정).
- `rain-thunder` — 이전 원본 `Rain and thunder (1).ogg` 는 천둥이 빗소리보다 8 dB 남짓 클 뿐이라 거의 묻혔다.
