# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this
repository. Do not open a public issue for security problems.

Include what you found, how to reproduce it, and which app version and platform you used.

Scope: this app. The robot's onboard software and Rainbow Robotics' services are out of scope for
public reports here, but if you find an issue in how the app talks to them, report it the same way.
