팔 제어 — Python 예제 ​

C++ · Python

소스: rbq_sdk/python/example/arm/

C++ 팔 제어의 Python 포팅입니다. 외부 앱에서 RBQ 에 달린 RBA-1 팔을 제어합니다. 예제에는 해 볼 순서대로 번호가 붙어 있고, 예제마다 한 가지 일을 하고 끝나며, 팔이 꺼져 있으면 각자 팔을 기동합니다(arm_helper.py).

예제단계하는 일
00_arm_help.py—SDK 버전과 설치된 위치를 출력하고, 예제 목록과 실행 방법을 출력합니다
01_arm_state.py상태팔 관절과 엔드이펙터 상태를 1 초에 두 번 출력합니다. 아무것도 보내지 않습니다
02_arm_power.py준비팔을 기동하거나, 상태를 출력하거나, 관절 제어 앱이 쥔 관절을 되찾거나, 팔을 멈추고(팔 비상정지) 다시 풉니다
03_arm_gripper.pyLv1그리퍼를 잠시 열거나 닫은 뒤 멈춥니다
04_arm_move_j.pyLv1 (관절 공간)내장 자세나 관절 각도로 MoveJ — 여섯 관절 또는 한 관절, 그 각도로 또는 그 각도만큼
05_arm_move_l.pyLv1 (태스크 공간)위치로 MoveL, 자세로 RotateL, 또는 둘 다. 또는 짧은 상대 이동 순서
06_arm_high_level.pyLv1 (태스크 공간)이 PC 의 게임패드로 엔드 이펙터를 움직입니다
07_arm_low_level.pyLv0 (관절)앱 슬롯 22 로 팔 관절 여섯 개를 가져와 500 Hz 로 관절 레퍼런스를 보낸 뒤 돌려줍니다. 직접 만든 FK·IK 는 my_arm.py 의 Controller(start, update)를 바꿉니다
08_arm_torque.pyLv0 (토크)팔 관절 여섯 개를 가져와 500 Hz 로 관절 토크를 보냅니다: 중력 보상과 출발 자세로 당기는 스프링

인자, 출력, 명령, 응답 코드, 관절 제어 규칙은 C++ 버전과 같습니다.

WARNING

팔은 사람이 다칠 만큼 빠르게 움직입니다. 팔이 닿는 범위에 사람이 없게 하고, 작은 동작부터 시작하고, 원격 비상정지를 손에 두세요.

사전 요구사항 ​

  • rbq_sdk_py 설치. 한 번도 설치하지 않은 PC 라면 Python SDK 개요를 따르고, 아니면 확인합니다.

    bash
    python3 -c "import rbq_sdk_py.arm as a; print(a.__file__)"

    에러가 나거나 이 저장소 밖의 경로가 나오면 다시 설치합니다.

    bash
    cd ~/RBQ/rbq_sdk/python     # ~/RBQ: 이 저장소를 받은 폴더
pip install -e .

  • 로봇 스택이 실행 중 — 이 PC 의 시뮬레이터, 또는 이 PC 에서 닿는 로봇.

  • RBA-1 팔을 단 RBQ, 서 있는 상태. 시뮬레이터에서는 bash scripts/sim.bash --robot rba-1로 띄우고, 웹 UI 에서 Auto Start → STAND 까지 진행합니다.

실행 ​

모든 예제는 대상을 첫 인자로 받습니다 — 이 PC 의 시뮬레이터는 sim(-s) 또는 생략, 192.168.0.10 의 로봇은 robot(-r). 자세한 것은 빌드를 보세요. 00_arm_help.py가 예제 목록을 출력하고, 예제마다 -h 로 자세한 설명을 출력합니다. 다른 예제를 실행하는 동안 01_arm_state.py를 터미널 하나에 켜 두세요.

bash
cd ~/RBQ/rbq_sdk/python/example/arm      # ~/RBQ: 이 저장소를 받은 폴더

python3 01_arm_state.py sim
python3 02_arm_power.py sim                     # on | status | release | estop | clear
python3 03_arm_gripper.py sim 1                 # 0 열기 / 1 닫기, [seconds]
python3 04_arm_move_j.py sim home               # 0 home, 1 ready, 2 straight, 3 pickup
python3 04_arm_move_j.py sim J1 120 2           # 또는 관절 각도: [abs|rel] <J0 .. J5> | J<n> <도>, [seconds | vel= acc=]
python3 05_arm_move_l.py sim                    # 데모
python3 05_arm_move_l.py sim pos 0.80 0 0.20 3  # [abs|rel] pos <x y z> | ori <roll pitch yaw> | pose <x y z roll pitch yaw>
python3 06_arm_high_level.py sim                # 이 PC 의 게임패드, [fast] [joystick]
python3 07_arm_low_level.py sim 0 20 4          # J0 를 20 도 갔다가 4 초 안에 돌아오기
python3 08_arm_torque.py sim 0 30               # 토크 제어: 중력만 30 초, [stiffness] [seconds]

인자마다의 설명은 C++ 버전에 있습니다 — 팔 상태, 팔 기동, 그리퍼, 관절 공간 이동, 태스크 공간 이동, 게임패드 태스크 공간 제어, 관절 제어, 토크 제어. 01_arm_state.py에는 온도 열이 없습니다.

직접 만든 알고리즘 넣기 ​

my_arm.py 는 직접 만든 FK·IK 나 플래너를 넣는 파일입니다. 예제와 같은 폴더에 있어 arm_helper.py 를 찾으므로 마음대로 고쳐 쓰면 됩니다. C++ 버전처럼 Controller 만 바꿉니다. 파일의 나머지는 팔을 기동하고, 매 틱 Controller 를 불러 돌려받은 값을 보내고, 끝나면 관절을 돌려줍니다. 먼저 팔을 Ready 로 옮기므로 시작 자세는 Ready 입니다. 처음 들어 있는 Controller 는 모든 관절을 시작 자세 기준 ±10° 사인 궤적(주기 4 초)으로 두 번 움직이고, 8 초 뒤 시작 자세에서 끝납니다. 게임패드를 주고 실행하면 대신 스틱으로 관절을 조그합니다(게임패드 참고). torque 를 주고 실행하면 같은 사인 궤적을 토크로 움직입니다(관절 명령과 토크 레퍼런스 참고).

start(s, arm) 은 관절을 넘겨받은 뒤 한 번 돕니다. update(t, s, pad, cmd, arm) 은 매 틱 돕니다: cmd.q 에 관절 레퍼런스 여섯 개 [rad] 를 넣고(관절 명령), 끝내려면 False 를 돌려줍니다. pad 는 지금 게임패드입니다(게임패드).

  1. Controller 의 >>> YOUR ALGORITHM 과 <<< YOUR ALGORITHM 사이에 알고리즘을 넣습니다. 아래는 my_kinematics.py 의 직접 만든 FK·IK 로 엔드이펙터를 8 초 동안 5 cm 올렸다가 내립니다:

    python
    import math

from my_kinematics import my_fk, my_ik  # your own: my_fk(q) -> [x, y, z], my_ik([x, y, z], seed) -> q, or None when out of reach


class Controller:
    T = 8.0

    def __init__(self):
        self.p0 = None      # end-effector position at the start
        self.q_last = None  # last joint references - the seed of the next IK

    def start(self, s, arm):
        self.q_last = list(s.q_ref)
        self.p0 = my_fk(s.q_ref)

    def update(self, t, s, pad, cmd, arm):
        if t > self.T:
            return False

        # >>> YOUR ALGORITHM: the end effector 5 cm up and back down in T seconds
        lift = 0.05 * 0.5 * (1.0 - math.cos(2.0 * math.pi * t / self.T))
        q = my_ik([self.p0[0], self.p0[1], self.p0[2] + lift], self.q_last)
        if q is not None:  # None: out of reach - stay where it is
            self.q_last = list(q)
        cmd.q = list(self.q_last)
        # <<< YOUR ALGORITHM
        return True

  2. 먼저 시뮬레이터에서 실행합니다:

    bash
    cd ~/RBQ/rbq_sdk/python/example/arm
python3 my_arm.py sim

직접 만든 프로그램을 더 추가하려면 .py 파일을 같은 폴더에 둡니다. 그래야 arm_helper.py 를 찾습니다.

s 의 필드는 C++ 와 같고 이름만 Python 식입니다 — q, dq, torque, q_ref, kp, kd, owner, gripper, ee_pos, ee_rpy, ee_valid, gravity, gravity_valid. 지킬 것도 같습니다.

arm 의 호출도 같고 이름만 Python 식입니다 — arm.set_gains(kp, kd)(게인), arm.send(q, vel, torque), arm.send_torque(torque, kd)(토크 모드), arm.gripper("open"). 게인은 여섯 개짜리 리스트입니다:

python
def start(self, s, arm):
    arm.set_gains([0.5 * k for k in s.kp], s.kd)  # 절반의 강성
    self.q0 = list(s.q_ref)

Python 은 500 Hz 를 따라가지 못할 수 있습니다. update 가 느리면 파일 위쪽의 RATE_HZ 를 낮추세요(예: 250).

관절 명령과 토크 레퍼런스 ​

update 는 매 틱 cmd 를 받습니다. main 이 보내는 관절 명령으로, 관절마다 위치 q, 속도 dq, 토크 tau, 게인 kp, kd 가 들어 있습니다. 각 관절 보드는 이것을 모터 토크로 바꿉니다:

text
motor torque = kp × (q − q_measured) + kd × (dq − dq_measured) + tau

main 은 부르기 전에 cmd 를 채워 두므로, 필요한 것만 바꾸면 됩니다:

값미리 채워지는 값매 틱 새로
q지난 틱에 보낸 위치(처음에는 시작 자세)아니요, 그대로 남음
dq, tau0예
kp팔 기본값: J0, J1 2632 Nm/rad, J2–J5 1190예
kd팔 기본값: J0, J1 21 Nm·s/rad, J2–J5 9.5예

아래 세 가지는 모두 같은 사인 궤적을 따라갑니다. >>> YOUR ALGORITHM 과 <<< YOUR ALGORITHM 사이의 이 루프 안에 하나를 넣습니다:

python
T, amp = 4.0, math.radians(10.0)
w = 2.0 * math.pi / T
if t > 2 * T:
    return False
for i in range(ARM_JOINTS):
    q_des = self.q0[i] + amp * math.sin(w * t)  # target position [rad]
    dq_des = amp * w * math.cos(w * t)          # target velocity [rad/s]
    # one of 1, 2, 3 below

1. 위치 제어, 중력 보상 없음. 관절 보드가 PD 로 위치를 따라갑니다:

python
cmd.q[i] = q_des
cmd.dq[i] = dq_des  # optional: the damping then works around the target velocity and the arm lags less
cmd.kp[i] = 1000.0  # your gains - leave these two lines out for the arm's own
cmd.kd[i] = 10.0
# cmd.tau stays 0

중력은 kp 가 오차를 만들어 버티는 방식이라, kp 를 낮출수록 팔이 처집니다.

2. 위치 제어, 중력 보상 있음. 1 에 중력 토크를 앞먹임으로 더합니다:

python
cmd.q[i] = q_des
cmd.dq[i] = dq_des
cmd.kp[i] = 300.0          # tau holds the arm against gravity, so a lower kp does not sag
cmd.kd[i] = 10.0
cmd.tau[i] = s.gravity[i]  # gravity torque as a feed-forward

새로 생긴 줄은 tau 하나입니다. 중력을 앞먹임이 맡으므로 kp 는 목표로 되돌리는 힘만 맡고, 게인을 낮춰 팔을 무르게 해도 처지지 않습니다(임피던스 제어).

3. 토크 제어. 관절 보드의 위치 제어를 끄고, 보낸 토크만 관절에 걸립니다:

python
cmd.kp[i] = 0.0     # the joint board's position control off
cmd.kd[i] = 0.0
cmd.q[i] = s.q[i]   # not used with kp 0 - keeps the hand-back smooth
cmd.dq[i] = 0.0
cmd.tau[i] = s.gravity[i] + 300.0 * (q_des - s.q[i]) + 10.0 * (dq_des - s.dq[i])  # the whole torque is yours

tau 에는 어떤 토크든 넣을 수 있습니다 — 예를 들어 5 Nm 를 걸려면 s.gravity[i] + 5.0. python3 my_arm.py sim torque 가 들어 있는 사인 궤적을 이렇게 움직입니다(J0, J1 300 Nm/rad·10 Nm·s/rad, J2–J5 150·5).

q, dqkp, kdtau
1. 위치목표원하는 게인, 또는 팔 기본값0
2. 위치 + 중력 보상목표원하는 게인s.gravity
3. 토크s.q, 00직접 만든 토크(s.gravity 포함)
  • cmd 는 관절마다 따로라서 섞을 수 있습니다 — 루프 안에서 J0 만 토크 제어, 나머지는 위치 제어. 바꾸지 않은 관절은 팔 기본 게인으로 지금 자세를 유지합니다.
  • 토크 제어에서 s.gravity 를 빼면 팔이 떨어지고, 감쇠 항이 없으면 관절이 계속 빨라집니다.
  • 프로그램의 토크 제어는 네트워크를 거쳐 500 Hz 로 돌므로, 관절 보드보다 낮은 게인에서 불안정해집니다. 단순히 무른 팔이 목적이면 2 가 낫습니다. 시뮬레이터에서 들어 있는 토크 사인은 위쪽 끝에서 최대 약 5°, 나머지에서 약 1° 늦습니다.
  • update 가 False 를 돌려주면 main 이 팔 기본 게인으로 되돌려 그 자리에서 관절을 돌려줍니다.
  • 코드 없이 한 관절에 정한 토크를 걸려면 08_arm_torque.py J<n> <Nm> 를 보세요.

게임패드 ​

C++ 버전처럼 my_arm.py 는 게임패드를 지정하면 이 PC 에 꽂힌 게임패드를 읽어 pad 로 update 에 넘깁니다. 처음 들어 있는 동작은 스틱으로 관절 조그, A / B 로 그리퍼 닫기 / 열기, BACK 으로 끝내기입니다.

bash
python3 my_arm.py sim joy                 # 처음 찾은 게임패드(또는 $JOY)
python3 my_arm.py sim /dev/input/js1      # 이 게임패드

pad 의 필드는 C++ 와 같습니다 — connected, lx, ly, rx, ry, held, pressed, axis. 버튼 번호(PAD_A … PAD_START)와 축 번호(AXIS_LEFT_X …)는 arm_helper.py 에 있습니다:

python
from arm_helper import PAD_BACK, PAD_LB

def update(self, t, s, pad, cmd, arm):
    if pad.pressed[PAD_BACK]:
        return False
    speed = 0.05 * (2.0 if pad.axis[5] > 0 else 1.0)  # [m/s], RT 를 누르면 두 배
    if pad.held[PAD_LB]:                               # LB 를 누르고 있는 동안만 움직인다
        self.p[0] += speed * pad.ly / RATE_HZ
        self.p[1] -= speed * pad.lx / RATE_HZ
        self.p[2] += speed * pad.ry / RATE_HZ
    q = my_ik(self.p, self.q_last)
    if q is not None:
        self.q_last = list(q)
    cmd.q = list(self.q_last)
    return True

ArmClient ​

코드를 짜지 않고 호출을 시험해 보려면 시험 도구 python3 arm_cli.py [target] 을 실행합니다 — 명령은 C++ arm_cli와 같습니다.

python
from rbq_sdk_py.core.channel import ChannelFactoryInitialize
from rbq_sdk_py.arm.arm_client import ArmClient
from rbq_sdk_py.arm.arm_api import ARM_POSE_READY, ARM_AXIS_Z

ChannelFactoryInitialize(0, "lo")   # 시뮬레이터. arm_helper.init_channel("robot") 은 192.168.0.10 으로 가는 장치를 찾는다
arm = ArmClient()
arm.SetTimeout(2.0)
arm.Init()                     # SportClient 처럼, 첫 호출 전에
arm.AutoStart()
arm.MoveJ(ARM_POSE_READY)
arm.Wait()                     # 팔이 도착할 때까지
arm.ControlStart()
arm.Wait()
arm.MoveLDelta(ARM_AXIS_Z, 0.02)
arm.Wait()
code, state = arm.GetState()   # state: 문자열 dict

메서드, 인자, 속도 상한, 응답 코드는 ArmClient에 정리돼 있습니다. 각도는 rad 입니다(30° 는 math.radians(30)) — SportClient 와 같습니다. Python 의 GetState()는 (code, dict)를 돌려주고, 이동 호출은 시간이나 상한을 키워드 인자로 받습니다.
