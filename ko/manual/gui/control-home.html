제어 홈 ​

제어 홈은 로봇을 조종하는 화면입니다. 허브에서 컨트롤을 눌러 엽니다. 화면 전체가 뷰포트여서 카메라 영상이나 3D 뷰가 여기에 나오고, 왼쪽에는 모션 카드, 오른쪽에는 관측 카드가 붙습니다. 게임패드가 없으면 아래 양쪽 구석에 가상 조이스틱이 하나씩 생깁니다.

DANGER

이 화면의 모션 버튼은 모두 실제 로봇을 움직입니다. 로봇이 움직이는 동안에는 사람·동물·장애물을 로봇에서 2 m 이상 떨어뜨려 두십시오. 버튼을 누르기 전에 주변을 살피고, E-STOP에 손이 닿는 자리에 있으십시오.

상단바 ​

상단바는 영상 위에 두 묶음으로 나뉘어 떠 있습니다. 왼쪽부터 순서대로 봅니다.

요소표시 / 동작
로고허브로 갑니다. 로봇은 그 자리에 서고, 연결은 끊기지 않습니다
상태 불빛초록·주황·빨강 중 하나가 천천히 깜빡입니다. 위험하면 빠르게 깜빡이고, 연결되지 않았으면 깜빡이지 않는 빨강입니다. 탭하면 시스템 종합 상태가 열립니다(연결 참고)
보행 칩로봇의 현재 보행 상태 이름을 상태별 색으로 보여 줍니다(예: STANDING). 연결되지 않았으면 보이지 않습니다
SLAM 칩외부 조종(SLAM·SDK)이 켜져 있을 때만 나타납니다. 탭하면 조종권이 앱으로 돌아옵니다
신호 막대WiFi 신호 세기와, 로봇 링크로 지금 오가는 속도
로그 배지아직 확인하지 않은 로그 알림
로봇 배터리, 기기 배터리로봇 배터리 잔량(충전 중이면 충전 표시)과 이 기기의 배터리
E-STOP비상 정지 — 아래에서 설명합니다
종료데스크탑 빌드에만 있습니다. 앱을 종료할까요? 로 한 번 물어본 뒤 앱을 닫습니다. 로봇은 계속 동작합니다

로봇이 끊긴 뒤 8초가 지나도 다시 붙지 않으면 앱이 스스로 허브로 넘어갑니다. 연결은 허브에서 하기 때문입니다. 연결된 로봇이 바뀌는 순간에도 허브로 돌아가니, 고르지 않은 로봇을 조종하게 될 일은 없습니다.

E-STOP ​

E-STOP은 한 번 탭으로는 발동하지 않습니다. 누르면 비상 정지하시겠습니까? 확인 창이 열리고, 로봇이 즉시 모든 동작을 멈추고 힘을 차단합니다. 제어를 다시 시작하려면 재초기화가 필요합니다. 라고 알려 줍니다. 정지를 누르면 실행하고, 취소를 누르면 돌아갑니다. 메뉴가 열려 있을 때를 포함해 어느 화면에서나 똑같이 동작합니다.

WARNING

비상 정지한 뒤에는 로봇에 모터 전원이 들어오지 않습니다. 다시 움직이려면 아래 자동 기동으로 되살려야 합니다. 시퀀스가 어디서 멈췄는지는 단계 칩이 알려 줍니다.

소유권 ​

로봇은 한 번에 한 기기만 조종합니다. 다른 기기가 제어권을 쥐고 있으면 상태 불빛이 주황으로 바뀌고, 시스템 종합 상태의 소유권 행에 가져오기 ▸ 가 뜹니다 — 탭하면 제어권을 되찾습니다. SLAM이나 SDK 프로그램이 조종하는 동안에는 대신 SLAM 칩이 보입니다.

자동 기동 ​

로봇의 모터 제어가 켜지기 전까지는 뷰포트 아래 중앙에 초록색 자동 기동 버튼이 떠 있습니다. 연결되지 않았으면 회색입니다. 탭하면 자동 기동 창이 열립니다. 창은 항상 화면 가운데에 고정됩니다 — 화면이 짧으면 창 안의 기동 시퀀스 목록만 스크롤되고 버튼은 늘 보입니다. 가로로 든 폰처럼 화면이 낮으면 단계마다 한 줄로 접혀 나오고, 줄을 탭하면 세부가 펼쳐지거나 접힙니다. 진행 중인 단계와 실패·경고가 난 단계는 저절로 펼쳐집니다.

  1. 안내를 먼저 읽습니다 — 로봇을 평평한 바닥에 두고 모든 발과 무릎이 지면에 닿아 있는지 확인하세요.
  2. 단계 칩 다섯 개가 시퀀스를 보여 줍니다: POWER, CAN-BUS, HOMING, IMU-CHECK, START. 아직 끝나지 않은 CAN-BUS·HOMING 칩은 탭해서 그 단계만 따로 돌릴 수 있습니다.
  3. 자동 기동을 누릅니다. 창은 그대로 열려 있고, 칩 아래 기동 시퀀스 패널이 사전 확인 → Leg 전원 → 관절 통신 → 모터 파라미터 → 홈 위치 → IMU → 제어 활성 순으로 통과 / 실패 / 경고 / 진행 중을 하나씩 채웁니다.
  4. 어느 단계가 실패하면 패널이 원인과 조치를 함께 알려 줍니다. 예를 들어 이미 서 있는 상태입니다 — 로봇을 앉힌 뒤 다시 시작하세요. 처럼 나옵니다. 조치한 뒤 다시 시작을 누릅니다.
  5. 시퀀스가 완료로 바뀌면 닫기를 누릅니다. 이 창에서 지켜본 기동이 마지막 단계까지 통과하면 다시 시작이 사라지고 닫기만 남습니다. 실수로 두 번 돌릴 일이 없습니다.

같은 시퀀스를 상태 불빛에서도 시작할 수 있습니다: 시스템 종합 상태 › ▶ 자동 기동 (전체 시퀀스).

뷰포트와 소스 선택 ​

뷰포트 위쪽 중앙의 드롭다운으로 무엇을 볼지 고릅니다. 로봇의 실시간 모델인 3D는 언제나 있고, 카메라 소스는 로봇이 그 카메라를 알아봤을 때만 목록에 올라옵니다: 전방, 후방, 좌측, 우측, 계단, 4분할, 파노라마, CCTV, 열화상, PTZ 합성, 그리고 LiDAR 장착 로봇의 SLAM. 목록 바깥을 탭하면 소스를 바꾸지 않고 닫힙니다.

PTZ 계열 소스를 고르면 팬·틸트·줌 패널이 영상 위에 뜹니다. 손잡이를 잡아 옮길 수 있습니다.

도킹이 도는 동안에는 선택기가 도킹으로 바뀌고 열리지 않습니다 — 닫을 때까지 뷰포트는 Dock View가 씁니다.

왼쪽 카드 — 모션 ​

로봇을 움직이는 것은 모두 왼쪽에 모여 있습니다.

  • 카드: 접혀 있으면 걷는 사람 아이콘이 든 둥근 유리 버튼입니다. 누르면 동그라미가 카드로 늘어나고, 카드 윗줄을 누르면 다시 접힙니다. 카드마다 펼침 상태를 기억하며, 처음에는 둘 다 펼쳐져 있습니다.
  • 본문: 고정 모션 버튼 SIT, STAND, WALK, STAIRS, DOCKING(도킹이 가능할 때만), 그리고 전체 모션 그리드를 여는 점선 버튼 모션이 있습니다. 로봇의 현재 보행 상태와 맞는 버튼이 강조됩니다. 모션 명령을 참고하세요.
  • 도구 버튼: 카드 밖, 왼쪽 조이스틱 바로 오른쪽에 작은 버튼이 한 줄로 놓입니다. 게임패드 모드에서는 왼쪽 가장자리로 갑니다. 하나를 누르면 그 줄 위로 해당 패널이 열립니다.
    • 주행 — 속도·본체 높이·기울기 슬라이더 (주행 파라미터).
    • 팔 — 매니퓰레이터가 달린 로봇에만 나옵니다.
    • 조종 — 입력 모드 자동 / 가상 / 패드와 실시간 게임패드 입력 맵. 자동은 물리 게임패드가 연결되면 그쪽으로 넘깁니다. 초록 점이 있으면 외부 조종이 주행을 맡고 있다는 뜻입니다.
  • 카드가 화면보다 길면 아래에 ▾가 붙어 스크롤된다는 것을 알려 줍니다.

오른쪽 카드 — 관측 ​

무엇을 보고 듣는가에 해당하는 것은 모두 오른쪽에 있습니다.

  • 카드: 접혀 있으면 둥근 유리 버튼이고, 펼치고 접는 방식은 왼쪽 카드와 같습니다.
  • 본문:
    • 비전 — 비전 토글이 모여 있습니다. P2G(Point-to-Go)도 여기 있는데, 소스가 전방일 때만 쓸 수 있습니다. P2G를 켜 두면 영상 속 바닥의 한 지점을 탭할 때 로봇이 그곳으로 걸어갑니다.
    • 3D 씬 — 3D 뷰 설정. 소스가 3D일 때만 나옵니다.
    • 오디오 — 로봇 소리 듣기, 볼륨, 장치. 초록 점이 있으면 듣기가 켜져 있습니다.
    • SLAM — LiDAR 장착 로봇에만 나옵니다.
    • PTZ — PTZ 카메라가 달린 로봇에만 나옵니다. 화면을 PTZ 카메라로 바꾸고, 다시 누르면 직전 소스로 돌아갑니다.
  • 워키토키: 오른쪽 아래 버튼입니다. 오른쪽 조이스틱 바로 왼쪽에 있고, 게임패드 모드에서는 오른쪽 가장자리로 갑니다. 누르고 있는 동안 로봇 스피커로 말이 나가며, 그동안 송출 중으로 표시됩니다. 스피커 앰프가 꺼져 있으면 흐리게 보이고 눌리지 않습니다.
  • 자이로와 속도 HUD는 영상 아래 중앙에 나란히 있습니다. 자이로를 탭하면 커집니다. 둘 다 앱 설정에서 끌 수 있습니다.

WARNING

P2G가 켜진 동안에는 영상 전체가 명령 영역입니다 — 바닥을 탭할 때마다 로봇이 움직입니다. 다 쓰면 반드시 끄십시오.

조이스틱과 입력 모드 ​

  • 게임패드가 없으면 — 터치 기기와 PC에서는 가상 조이스틱 두 개가 나옵니다. 축이 무엇을 하는지는 현재 모션에 따라 달라집니다. 모션 명령의 축 표를 보세요.
  • 게임패드가 있으면 — 물리 패드든 Steam Deck이든 가상 조이스틱이 사라지고 패드의 스틱으로 조종합니다. 영상을 넓게 보려면 카드를 접으십시오.
  • 앱 설정 › 게임패드의 원 스틱 모드는 좌우 스틱 역할을 바꿔 한 손으로도 조종할 수 있게 합니다.

키보드로 조종하기 — 게임패드가 없는 PC에서는 가상 조이스틱과 함께 키보드로도 조종할 수 있습니다. 이 화면에서만 듣습니다. 허브나 설정에서는 같은 키를 눌러도 로봇이 꿈쩍하지 않습니다.

키를 누르고 있는 동안 로봇이 움직이고, 떼면 멈춥니다. 키보드에는 비상 정지 키가 없습니다 — E-STOP은 화면 오른쪽 위 버튼입니다.

연결된 동안에는 왼쪽 아래 구석에 현재 보행 상태 이름이 작은 HUD로 뜹니다.

컴팩트 레이아웃 ​

세로가 짧은 화면, 그러니까 폰이나 높이 500 px 미만의 창에서는 배치를 그대로 두고 요소만 작아집니다. 조이스틱·도구 버튼·워키토키는 구석으로 작게 들어가고, 왼쪽 카드는 그 위 공간까지만 차지하며 스크롤됩니다. 가로가 좁은 화면에서는 카드 폭도 좁아집니다. 빠지는 기능은 없습니다.

개발자 모드에서 더 나오는 것은 개발자 모드에 모아 두었습니다.
